# Event Booking System

A web application that allows users to discover, book, and organize events online. Built with Python and Django for efficient event management!

A project I finished during my internship at Shadhin Lab LLC. I learned a lot and had fun building and customizing the website. Had an amazing time!

Features:
- User registration and authentication
- Event creation and management for organizers
- Event listing and search for attendees
- Booking/reservation system
- Admin dashboard for managing users and events
- Attendee dashboard for booking and cancelling events
- Responsive design for mobile and desktop
- PayPal support
